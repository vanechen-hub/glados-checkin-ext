GLaDOS 签到助手 (v1.5.7)

💡 运行机制说明（v1.5.7）：

📡 采样：每 5 分钟读取一次服务端网络质量（/api/user/iqi）并落盘，保留最近 14 天。 签到页开着时由页面采样，页面关了则由后台自动接手，不依赖标签页存在。

🟠 签到条件（v1.5.6 放宽）：采样到 quality.score < 85（加成档 +5 / +8）或等级为 Poor 时自动签到， Good 等高分档只记录、不签到。旧版死等 Poor（仅 +8 档），多数日子网络只在 80~85 徘徊 → 整天空转、最后掉到 21:00 兜底拿 1 分。 想只等 +8 档，把 background.js / content.js 里的 BONUS_SCORE_MAX 改成 80。

📉 关于页面上的 "Cable +N"：那是签到页用打开页面那一刻缓存的 iqi.quality.score 在前端算的 预估（score<80→+8 / <85→+5 / <90→+3 / <=95→+2 / >95→+1），不是结算承诺； 实际加分由服务端在签到那一刻返回 points 决定。页面 IQI 只在加载时取一次、不会刷新，所以常见「显示 +5，点了只给 2」。 11-13 实测：扩展在 触发score=82（按上表 = +5 档）签到，服务端仍只返回 Checkin! Got 1 Points。 即 score 与实发分没有对应关系——BONUS_SCORE_MAX 只决定「何时签」，不会提升分值。 本扩展每 5 分钟 no-store 重取，比常开页面的缓存新鲜；历史里会记 触发score 与 实发N分 供你对照校准。

🛟 兜底保护：当天 21:00 起仍未签到时，无视网络等级强制签到。 判定窗口为 21:00–23:59（3 小时），期间每 5 分钟采样闹钟都会检查一次，约 36 次机会， 任一时刻机器醒着就能签上。即使签到页没打开，后台也会直接调 API 提交，并刷新一次签到页。

🔐 设备不匹配：GLaDOS 改版后引入设备绑定校验。若判定会话/设备异常，签到会返回 code=4 / device-mismatch 并弹「重新登录」弹窗，自动化无法代为越过。此时扩展会： ① 在徽标与历史里明确提示「⚠ 设备不匹配/会话失效，请重新登录 GLaDOS」；② 不误判为已签到（旧版曾把含 “get” 的错误提示误当成功，导致静默断签）；③ 持续重试，你手动重新登录后自动恢复。

🌐 域名：自动适配 glados.cloud / glados-facility.com / glados.rocks / glados.space / glados.one / glados.network，会自动识别你实际登录的是哪一个。

🔏 工作量证明（v1.5.5 修复）：GLaDOS 改版后签到接口强制要求 PoW 挑战——须先 GET /api/user/checkin/challenge 取 nonce，再算 SHA-256(nonce + "glados-observer-v1") 作为 proof 一并提交。旧版只发 {token} 会被服务端拒签（或降级成 1 分）。本版已在后台完整复刻该流程， 且不再依赖点击页面按钮（改版后按钮类名已变），改成统一由后台直接调 API，关掉签到页也能签。

⚠️ 前提：当前浏览器需已登录任一 GLaDOS 站点，例如 glados-facility.com。 未登录时下方采样面板会显示「未登录」。
